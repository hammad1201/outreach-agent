Kite Labs is a two-person web studio in Manchester, UK, run by Alex Morgan.

What we do:
- Online booking for local service businesses: customers pick a time on the website or Instagram,
  get reminders by text, and the owner sees the day on their phone. Replaces phone and DM booking.
- Simple, fast websites for the same businesses, built so the owner can edit prices and photos.

How we work:
- Small fixed-price projects, usually live in two to three weeks.
- We set everything up and show staff how to use it. No long contracts.

Proof we can mention:
- Built booking for a three-chair barbershop in Leeds that cut no-shows noticeably after reminders went live.
- Rebuilt the website for a family-run physio clinic; enquiries now come through the site instead of the phone.

Who we don't work with: large chains, franchises, medical providers needing patient-record systems.
